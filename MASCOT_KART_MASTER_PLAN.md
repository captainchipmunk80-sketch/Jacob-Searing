# Sweetie's Apple iStadium Mascot Kart Race Master Plan

## Purpose
This master plan connects the race rulebook, staff handbook, kids rules card, event poster, and event forms into one complete operating package for Sweetie's Apple iStadium Mascot Kart Race.

## Document Map
| Document | Audience | Use |
|---|---|---|
| `MASCOT_KART_RULEBOOK.md` | Race directors, partners, marshals | Defines official rules, classes, scoring, penalties, safety, and planning roadmaps |
| `MASCOT_KART_STAFF_HANDBOOK.md` | Staff and volunteers | Explains race-day roles, opening steps, session flow, announcements, incident response, and closing steps |
| `MASCOT_KART_KIDS_QUICK_RULES.md` | Kids, junior mascots, guardians | Gives simple safety promises, light signals, and before/during/after race reminders |
| `MASCOT_KART_EVENT_POSTER.md` | Families and public guests | Promotes the event and highlights race classes, family features, and safety-first messaging |
| `MASCOT_KART_EVENT_FORMS.md` | Staff and operations leads | Provides printable forms for checks, scoring, incidents, youth release, and closing records |

## Launch Plan
### Phase 1: Prepare
- Review the rulebook with race directors, safety leads, and partner teams.
- Print the staff handbook and event forms for the operations desk.
- Print the kids quick rules card for briefing stations.
- Post the family event poster near entry, ticketing, and spectator areas.

### Phase 2: Train
- Run a staff tabletop exercise using the incident report form.
- Practice green, yellow, red, blue, and black signal responses.
- Confirm every marshal knows the youth release process.
- Test timing, scoring, radios, race lights, and announcement scripts.

### Phase 3: Soft Open
- Start with Class K Kids Fun Laps and Class J Junior Mascot Cup only.
- Limit each session to reduced capacity while staff validate the flow.
- Complete opening, kart inspection, driver check-in, scoring, and closing forms.
- Debrief after each session and update operating notes.

### Phase 4: Full Program
- Add Class A Adult Mascot Challenge and Class P Partner Team Relay.
- Schedule weekly family, school, partner, and championship blocks.
- Use the score sheet for seasonal points and awards.
- Review incidents weekly and adjust staffing or track controls as needed.

## Race-Day Timeline
| Time Block | Activity | Primary Documents |
|---|---|---|
| Pre-open | Track walk, kart checks, radios, staff huddle | Staff Handbook, Event Forms |
| Morning | Kids Fun Laps and junior safety sessions | Rulebook, Kids Quick Rules, Event Forms |
| Midday | Family sessions and spectator engagement | Poster, Kids Quick Rules |
| Afternoon | Qualifiers, partner relays, scoring updates | Rulebook, Event Forms |
| Evening | Showcase race, awards, closing reset | Staff Handbook, Event Forms |

## Readiness Checklist
- Rulebook approved by race director and safety lead.
- Staff handbook reviewed by every assigned role.
- Kids quick rules available at briefing and pickup points.
- Event poster placed in public guest areas.
- Event forms printed or available digitally.
- Karts inspected before public sessions.
- Medical response coverage confirmed.
- Youth pickup checkpoint staffed.
- Incident reports reviewed before restart decisions.

## Success Measures
- Zero unresolved safety incidents at closing.
- Every session has completed check-in and scoring records.
- Youth release records are complete for Class K and Class J.
- Average guest wait time stays below the growth-plan threshold.
- Staff debrief produces clear improvements for the next event day.
